# Changelog

This project follows semantic versioning after v1.0. Before v1.0, minor releases may include configuration changes documented here.

## 0.1.0 — 2026-09-05

- Initial TypeScript CLI and reusable library API.
- Responsive overflow, contrast, touch-target, alignment, and spacing checks.
- Protected-region baselines and pixel diffs.
- Terminal, Markdown, JSON, and GitHub annotation reporters.
- Bundled GitHub Action.
- Optional structured OpenAI screenshot review that remains advisory.
- Cross-platform test and release workflows, demo fixtures, and contributor documentation.
