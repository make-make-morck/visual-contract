# Roadmap

This roadmap communicates intent, not guaranteed delivery dates.

## v0.2 — integration hardening

- Authentication setup hooks and cookie/storage-state support.
- Named ignore zones for dynamic protected-region content.
- JUnit and SARIF reporters.
- Public JSON Schema and editor completions for configuration.

## v0.3 — designer workflow

- Interactive rule recorder that proposes stable selectors.
- Design-token checks for color, radius, type scale, and spacing scale.
- Better evidence blocks with DOM bounds and computed styles.

## v0.4 — ecosystem

- Monorepo and multi-page project configuration.
- GitHub pull-request comment updater.
- Documented adapters for Storybook, Vite, Next.js, and component previews.

## v1.0 readiness

- Stable YAML and report schemas.
- Benchmarked false-positive fixtures across browsers and operating systems.
- Security review, contributor governance, and predictable release policy.
