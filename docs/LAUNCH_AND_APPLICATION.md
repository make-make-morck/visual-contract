# Honest launch and Codex for Open Source application

This repository is an implementation-ready v0.1.0 MVP. It is not evidence of public adoption until it has been published and used by independent projects.

## Before publishing

1. Confirm that the npm package name is still available at publish time.
2. Create the public `make-make-morck/visual-contract` GitHub repository and push this history.
3. Enable Issues, Discussions, private vulnerability reporting, and branch protection.
4. Add the `NPM_TOKEN` repository secret or configure npm trusted publishing.
5. Run CI on all three operating systems; do not publish if any required check fails.
6. Create the `v0.1.0` tag only after reviewing the generated `action-dist` bundle.

## Evidence to build before applying

- A public release page and reproducible one-minute demo.
- Two or three honest releases with changelogs.
- Real issues and pull requests that demonstrate active maintenance.
- At least three independent public repositories using the CLI or action.
- Verifiable GitHub stars, npm downloads, and external adopter links.

Do not buy stars, manufacture downloads, create fake users, or describe forks as independent adopters. OpenAI has not published a guaranteed minimum threshold.
